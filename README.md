# KincsesLádák MVC

Ez a projekt egy konzolos Java alkalmazás, amely a "KincsesLádák" logikai feladatot valósítja meg MVC (Model-View-Controller) architektúra használatával.
A játékban/feladatban 3 ládánk van amelyek mindegyikének van egy-egy felirata.
Tudjuk hogy a feliratokból avagy állításokból csak az egyik igaz, és ez alapján kell kitalálnunk hogy melyik rejtheti a kincset!
